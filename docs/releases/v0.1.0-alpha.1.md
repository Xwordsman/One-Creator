# v0.1.0-alpha.1 发布说明

发布日期：2026-10-23

One-Creator 的第一个公开 alpha 版本。它是一个可自部署的 AI 自媒体工作台，把账号人设、灵感素材、母稿与多平台版本、AI 辅助、排版导出、发布记录和复盘放在同一个 Web 工作台里。

## 这个版本包含什么

### 创作与素材

- 账号档案、平台与分类、可版本化的创作人设与账号偏好；同一平台多账号。
- 灵感池、文字 / 链接 / 图片素材、Markdown 导入、搜索与归档；素材可关联灵感。
- 摘录级引用：从保存的原文中选取片段，保留引用快照；原文变化和模型新增的来源标记待核实。
- 母稿派生为指定账号的平台版本，各自保留独立内容与写作上下文；修订历史、比较、恢复与并发冲突处理。
- 发布前字段检查，只提示不自动截断。

### AI 辅助

- 自带 OpenAI Chat Completions 兼容接入：大纲、标题候选、开头备选、正文、平台改写，选中段落改写 / 扩写 / 缩写。
- 写作预设（变量、适用步骤、参数说明）、多步骤工作流、栏目系列、视觉模板、审校词典、对标观察。
- 样文风格提炼、按账号推荐选题、语言审校、事实辅助核对、内容复盘、评论回复草稿。
- 结果先作为候选，逐项采用；采用意见可形成偏好建议。任务支持取消、重试和采用记录。

### 资料与检索

- RSS / Atom / JSON Feed 订阅，网页正文提取与历史文章批量导入。
- 语义检索：配置向量服务时使用向量；不可用时回退关键词。

### 排版与多平台

- Markdown 编辑、即时预览、公众号风格内联样式、视觉模板、富文本复制、HTML / ZIP 导出。
- 小红书文字卡片分页与 PNG / ZIP 导出；封面裁剪；按平台给出标题、摘要和标签建议。

### 发布

- 公众号：AppID / AppSecret 连接与权限检查、正文图片和封面上传、官方草稿、正式发布、结果查询与已发表文章指标同步。草稿成功与正式发文分开记录。
- 浏览器执行节点（`apps/executor`）：小红书图文、头条文章、知乎专栏文章、百家号图文、B 站视频投稿。Web 内扫码登录，平台会话只保存在节点并加密；发布前后核对实际登录账号。
- 只有当前账号已有一条经节点核验的发布记录，通道才显示“可用”。
- 发布日历、冻结版本的发布包、平台链接与实际发布时间回填；逐条选择是否到时自动执行。结果不确定时只查询，不自动重发。

### 视频

- 可选 FFmpeg 媒体服务（`apps/media-service`）：音视频转写进入素材库与可编辑转写、视频脚本、配音合成短视频、长视频切片。
- 切片可对照播放器选取区间、只播放片段预览、越界提示；每段导出视频、封面、字幕与文案，并记录原片区间。
- 基础部署不需要 FFmpeg、GPU 或向量数据库。

### 数据、团队与开放接口

- 手工 / CSV 指标、公众号指标同步、表现看板；合作与收益台账。
- 管理 / 编辑 / 只读成员与账号授权、站内通知、模型用量与费用。
- REST API（`/api/v1`、OpenAPI）、访问令牌、签名 Webhook、MCP。
- 数据与素材备份、空实例恢复；恢复后外部凭据作废、过时计划等待确认。

## 快速开始

### 本地运行

需要 Node.js 22.12+（推荐 24），首次安装需要联网。

```sh
git clone https://github.com/Xwordsman/One-Creator.git
cd One-Creator
npm install
npm run dev
```

打开 <http://localhost:5173>，创建自己的工作台账号。默认使用 PGlite 和进程内 worker，数据保存在 `.data/local/`，不需要先安装数据库。在「设置 → 文本模型」填写自己的服务地址、模型 ID 和 API Key。

### Docker 自部署

在服务器上克隆仓库后，在仓库目录中执行：

```sh
node scripts/setup-docker.mjs
docker compose --env-file deploy/.env -f deploy/compose.yaml up -d --build
```

打开 <http://localhost:8080>。服务器部署先编辑 `deploy/.env`，将 `APP_ORIGIN` 设置为实际访问地址；使用 HTTPS 时设置 `COOKIE_SECURE=true`。Compose 包含 Web/API、独立 worker、PostgreSQL 17 和持久化卷；视频服务（`--profile media`）与浏览器执行节点（`--profile executor`）为可选项。

## 验收状态

69 项需求全部有实现：**40 项 `DONE`、29 项 `VERIFY`**。`VERIFY` 表示功能已实现并通过模拟服务或本地页面验证，但验收依赖本机没有的外部条件，没有把模拟结果记为真实验收：

| 还缺的条件 | 涉及能力 |
| --- | --- |
| 真实 AI 服务（文本、图片、向量、转写、语音） | 分步写作、风格提炼、选题推荐、审校、事实核对、配图、语义检索、复盘、回复草稿、用量统计等 |
| 有权限的真实公众号 | 账号连接、草稿、正式发布、数据同步、后台排版粘贴 |
| 小红书 / 头条 / 知乎 / 百家号 / B 站真实账号 | 浏览器发布通道 |
| Docker 与 PostgreSQL 环境 | 容器部署、升级恢复、多进程定时调度 |
| 真实语音合成服务与媒体服务镜像 | 短视频合成 |

逐项证据与限制见 [开发进度](../progress.md)。

## 已知限制

- 这是 alpha 版本，接口、数据结构和页面仍可能调整；升级前请先备份。
- 当前开发环境没有 Docker，Compose、外部 PostgreSQL 以及 `media` / `executor` 容器镜像尚未实测。
- 真实模型服务、公众号账号和浏览器平台后台尚未验收。平台页面选择器按公开页面编写，平台改版后可能需要校准。
- 语音合成走兼容接口，当前只用模拟服务验证过协议。
- 公众号草稿成功不代表正式发文，正式发布也不是群发。
