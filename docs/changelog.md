- 范围细化（不改变需求 ID）：
  - 日历默认只作计划，自动执行需逐条选择；错过 10 分钟以上默认等待确认。
  - 浏览器通道只在本账号有经节点核验的发布后显示“可用”。
  - 备份恢复后 API 令牌撤销、Webhook 停用、节点令牌作废、浏览器登录失效，过期的自动执行计划不会自行补发。
  - 订阅、网页导入和 Webhook 只访问公网地址；管理员配置的模型 / 媒体服务地址不受此限制。
- 安全修复：授权改为按匹配到的路由判断（百分号编码路径可绕过）；重试平台发布任务同样需要 `publish:write`。
- 视频切片改为对照播放器选取、预览与调整片段；隔离预览自带真实 FFmpeg 媒体服务，浏览器流程覆盖转写、合成与切片。`VID-03` 转为 `DONE`。
- 更新 README、部署说明、开发指南、`.env.example` 与决策记录。
